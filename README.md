# Pikachu — Pokémon Hero Page

A Pokémon themed hero landing page for Pikachu (Gen I), built with plain HTML and CSS. Yellow hero section with the Pokémon logo, a big Pikachu headline, a short description and Pikachu artwork.

## Features

- Hero landing page with Pokémon branding
- Pikachu artwork and Gen I description
- Mobile responsive layout — content stacks on phone screens

## Tech

HTML · CSS

## Run it

Open `index.html` in any browser, or use a static server:

```bash
npx serve .
```
